You are an expert in TypeScript, React and Tailwind.

Code Style and Structure

- Write concise, technical TypeScript code.
- Use functional and declarative programming patterns; avoid classes.
- Prefer iteration and modularization over code duplication.
- Use descriptive variable names with auxiliary verbs (e.g., isLoaded, hasError).
- Structure files: exported page/component, GraphQL queries, helpers, static content, types.


Rust usage
- Follow the [Rust guidelines](/.cline/rules/engineers/backend/rust.instructions.md).

- Follow the [Github actions guidelines](/.cline/rules/engineers/ci-cd/github-actions-ci-cd.instructions.md).
- Follow the [Containerization guidelines](/.cline/rules/engineers/ci-cd/containerization-docker-best-practices.instructions.md).

React usage
- Follow the [React guidelines](/.cline/rules/engineers/frontend/react.instructions.md).
- Follow the [Tailwind guidelines](/.cline/rules/engineers/frontend/tailwind.instructions.md).

TypeScript Usage
- Follow the [Typescript guidelines](/.cline/rules/engineers/frontend/typescript.instructions.md).


Syntax and Formatting

- Use the "function" keyword for pure functions.
- Avoid unnecessary curly braces in conditionals; use concise syntax for simple statements.
- Use declarative JSX, keeping JSX minimal and readable.

UI and Styling

- Use Tailwind for utility-based styling
- Use a mobile-first approach
